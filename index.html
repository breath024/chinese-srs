성조 (4성 + 경성)

1성
평성 — 높고 평평. 일정 톤 유지. (妈 mā)
2성
상승 — 중간에서 위로. 한국어 "뭐?" 끝 올림 느낌. (麻 má)
3성
하강상승 — 내렸다가 올림. 짧을 땐 낮은 톤만. (马 mǎ)
4성
하강 — 위에서 아래로 뚝. 한국어 "야!" 짧게 외치는 느낌. (骂 mà)
경성
짧고 가볍게 — 앞 글자에 묻어가는 가벼운 소리. (吗 ma)

자음 — 한국인이 자주 헷갈리는 것

b / pb는 부드러운 "ㅃ"(공기 적음), p는 거센 "ㅍ"(숨 강하게). 한국 ㅂ과 ㅍ보다 차이 큼. d / td는 "ㄸ", t는 거센 "ㅌ". 숨 차이. g / kg는 "ㄲ", k는 거센 "ㅋ". zh / ch / sh / r혀끝을 입천장 쪽으로 말아 올림. zh="줘"의 ㅈ, ch="추"의 ㅊ, sh="슈"의 ㅅ, r은 "ㄹ과 ㅈ 중간"의 권설음. (吃 chī, 是 shì, 人 rén) j / q / x평평한 혀로 앞쪽에서. j="지", q="치"(거센), x="시". 입을 옆으로 벌림. (鸡 jī, 七 qī, 西 xī) z / c / s혀끝이 위 잇몸 뒤. z="ㅉ", c="ㅊ"(거센), s="ㅆ". 영어 ts 비슷. (字 zì, 次 cì, 四 sì)

모음 — 까다로운 것

ü (v)"위"인데 입술 둥글게. 한국어 "위" + 입술 모음. j/q/x/y 뒤에서는 u로 표기되지만 발음은 ü. (女 nǚ, 去 qù) e단독 e는 "어"에 가까움. 입 모양은 "에"이지만 소리는 "어". (饿 è, 哥 gē) -i (zi,ci,si,zhi,chi,shi,ri 뒤)"이"가 아니라 "으"에 가까운 짧은 소리. (子 zi="쯔", 是 shì="스") -r (儿화)단어 끝에 儿이 붙으면 혀를 살짝 말며 r색을 더함. (一点儿 yìdiǎnr — "이디알" 비슷) -ian / -üan"이안"이 아니라 "이엔". (天 tiān = "톈", 元 yuán = "위엔")

변조 (Tone Sandhi) — 자주 나오는 규칙

3성+3성앞 3성이 2성으로 바뀜. 你好 nǐ hǎo는 실제로 "ní hǎo". 不 (4성)뒤에 4성이 오면 不는 2성으로. 不是 bú shì, 不见 bú jiàn. 一 (1성)뒤 4성 앞 → 2성 (yí), 1·2·3성 앞 → 4성 (yì). 단독·서수일 땐 1성.
